任务 T0.1：拆分 kernel/src/main.rs 里的内核用例（纯搬移，不改任何行为）

【背景（我已核实的事实，开工前请你自己再核一遍）】
- main.rs 约 7,618 行。73 条 `ktest!` 注册，但有 74 个 `fn t_`：差的那一个请在盘点表里解释。
- 用例通过 `.ktests` 链接段注册（ktest.rs + linker.ld）。执行顺序 = 链接顺序，不是源码顺序。
- main.rs 里有 50 个非 `t_` 的顶层项：kmain、on_panic、after_switch、
  exit_fatal_from_exception、mp_store/mp_snapshot、GLOBAL、RSDP_VA 等是非测试代码；
  其余多是用例的辅助（HELLO_ELF、ELF_BUF、with_elf_copy、drain_reap、run_one、
  p2_probe、fat32_file、FAT32_MEM、PKG_BUF 等）。
- 其他文件引用了 main.rs 里的项：smp.rs 用 crate::mp_snapshot、crate::calibrate_clock_once；
  trap.rs 用 crate::exit_fatal_from_exception；handle.rs 用 crate::HELLO_ELF、crate::drain_reap。
- 宿主机门禁直接读 main.rs 文本：tools/aurora.py 的 check_fat32_ports（读 FAT_PORT_* 常量、
  want 表、feature 名、串口锚点）、check_virtio_pattern 与 check_net_pattern（读 EXPECT_PATTERN）。
- unsafe 普查按文件路径记模块（模块名 = 相对 kernel/src 的路径去掉后缀），
  docs/security/unsafe-whitelist.toml 里有 [modules."main"] 一项（U1=3 U4=8 U6=18）。
- 仓库文件是 CRLF 换行。

【目标】把用例及其专用辅助搬到 kernel/src/ktests/*.rs，按被测子系统分文件
（例如 boot、mm、heap、acpi、sched、user、syscall、driver、virtio、net、fs、handle、sign）。
main.rs 只留启动入口与非测试代码。

【硬约束】
1. 纯搬移：不得改任何函数体、断言、判据、字符串、打印文本、cfg/feature 属性。
   唯一允许的代码改动：mod 声明、use、为跨文件引用放宽到 pub(crate)、
   用 `pub(crate) use` 保持上面 5 个外部引用路径可用。
2. 不得合并、删除、重命名用例；不得改 tools/ 里的期望值或阈值；不得改 Cargo features。
3. 不得对整个仓库运行 cargo fmt（会制造巨大 diff）。
4. 搬移必须用脚本按行区间切片（脚本放 .scratch/，不入库），不要手敲或让编辑器重排；
   新文件沿用 CRLF。
