# ADR-101：`∨` 下拉——会话在上、动作在下

状态：采纳（2026-11-14，S6w）
关联：ADR-100（标签条语义与悬停）、ADR-097/098（关闭与重开）、BACKLOG §290

## 背景

`∨` 此前被拿去做"标签条 ⇄ 浮窗版面"的开关（ADR-097）。参考图里它明确是**新标签下拉**：
上面是会话/配置列表，下面是设置一类动作。用户裁决要按参考图做，且列表分两段：
**会话在上、profile 在下**。

## 决策

1. **`∨` 开下拉面板**；"浮窗版面"从 `∨` 移进面板第 3 行（动作不丢，换了入口）。
2. 面板几何一份：`MENU_W = 30` 格、最多 6 行、贴屏幕右边、第 1 格行开始；
   `menu_rect` / `menu_hit` / `Term::menu_panel` 共用（绘制与命中不各算一遍）。
3. 配色沿用参考的面板层次：底 `#2C2C2C`、悬停行 `#3A3A3A`、左边缘一道 `#4A4A4A`。
4. 行内容按裁决：`会话 0`（Ctrl+Shift+1）、`会话 1`（Ctrl+Shift+2）、`浮窗版面`、
   `新建 shell`（**置灰**，提示"16 格句柄表"）。
5. **置灰行点了要如实报墙**，不假装成功：`菜单: 新建 shell 撞容量墙（句柄表 16 格，两会话已占 15）`。
6. 面板开着时这一击**归面板**：点行执行后关闭，点面板外只关闭——
   **消费掉就不再落到下面的正文/标签**（否则关面板那一下会顺手点到东西）。
7. 面板状态（开/悬停行）进重画签名。

（整块 61440，扣文字与边线）→ 点第 1 行 ⇒ `菜单: 切到会话 0 ⇒ 关` 且面板色残留 **0**。
`s6t`/`s6r` 的"进浮窗"改成菜单路径后仍 **PASS**；`check` **17/17**。
