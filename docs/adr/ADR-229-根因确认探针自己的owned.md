# ADR-229：根因确认 —— 探针**自己**的 `owned` 被回收撤了自己的页

状态：**已核实**（2026-11-23：slot 分桶计数 4/20 全部命中 slot 2）

关联：ADR-228（证明「窗口内容器段被撤」）、ADR-227（heisenbug）

> ADR-228 证明「窗口内某被 reap 任务的 `owned` 含容器段」，但不知道是哪个。
> 本 ADR 按 slot 分桶，**答案是：探针自己。**

## 手段：按 slot 分桶的原子计数

```rust
// release_owned 里，搬出映射之前
for i in 0..n0.min(MAX_OWNED) {
    if let Some(OwnedItem::Map(m)) = s0.tasks[slot].owned.items[i].as_ref() {
        if m.virt().0 >= 0x1000_c0000 && m.virt().0 < 0x1000_d0000 {
            hit = true;
        }
    }
}
if hit { CONTAINER_OWNED_SLOTS.fetch_add(1, ...); CONTAINER_OWNED_LAST.store(slot, ...); }
```

纯原子操作，不写串口（ADR-227 的教训）。

## 结果：4/20 失败，全部命中 `slot=2`

| 次 | FAIL | 读数 |
|---|---|---|
| 5 | `t_fs_open_ring3` | `容器段撤映射=0→2 容器段owned=0→1(slot=→2)` |
| 6 | `t_sdkdemo` | `0→0 / 0→0`（**与容器段无关**，另一条路）|
| 8 | `t_fs_open_ring3` | `容器段撤映射=0→2 容器段owned=0→1(slot=→2)` |
| 19 | `t_fs_open_ring3` | 同上 |

**3 次 `t_fs_open_ring3` 失败全部是 `slot=2`。**

而同一份日志里的 `探针gidx=2` —— **slot 2 就是探针自己的槽**。

## 根因（最终）

```
探针跑完 => 自己 exit => 任务变 Done
  => 下一个抢占点 reap 它 => release_owned 取出 owned（含容器段 Mapping）
  => Mapping::drop 撤掉容器数据页
  => 内核窗口还在等 DONE 哨兵 / 读快照 => 读到全 0
```

**这不是「别的任务误伤」，是「探针自己的页在自己退出后被正常回收」。**

## 这解释了三件事

### 1. 为什么 `映射窗口后=false`

页被回收了，不会回来。ADR-225 曾据此判断「短暂不可达、之后又好了」——
那是**另一次运行**的读数，不是同一跑的前后对比。

### 2. 为什么 `换人 338→342`（不是早期）

探针要先跑完（`served=34`）才会退出。窗口前 338 次换人是它在跑。

### 3. 为什么 `reap=134→138`（窗口内 +4）

其中一个就是探针自己。

## 这不是 bug，是**测试的时序假设错了**

测试的注释（`fs_open.rs:789-792`）已经写过这件事：

> 两段窗口：第一段只等 `DONE`，看到就**退出**——`with_interrupts` 退出时 `cli`，
> 于是下面的整页快照与异步 reaper 互斥。
> 旧版把快照放在整段窗口之后……那期间任何一次 tick 都会把已 Done 的容器回收、
> 把它的页还掉，`read_at` 便读到「页表链没走完」的全 0（§366）。

**测试作者已经知道这个坑，并且用「看到 DONE 就退出窗口」来规避。**

但当探针**在写 DONE 之前就退出**（或 DONE 写了但窗口没及时看到）时，规避失效：

```
探针 exit（未写 DONE 或写了但窗口没读到）
  => reaper 回收 => 页没了
  => 窗口永远等不到 DONE => 超时
  => 快照全 0
```

## 所以真正要查的是

**探针为什么有时不写 DONE？** 两种可能：

1. 探针在某个 syscall 上失败提前 `exit`（那 `served=34` 应该更少，但读数一样）；
2. 探针写了 DONE，但窗口的 `slot(data, fp::DONE)` 读失败（`被拒=58424` 说明读确实大量失败）。

**第 2 条更可能**：页在写 DONE 之前就被撤了 —— 但那需要探针先退出，矛盾。

除非：**探针的 `exit` 与「写 DONE」的可见性之间有时间差** —— 写是 store，exit 是 syscall，
两者之间 reaper 可能已经跑过。
