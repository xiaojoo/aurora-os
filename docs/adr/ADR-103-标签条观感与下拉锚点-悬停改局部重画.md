# ADR-103：标签条观感与下拉锚点——局部重画取代"悬停进整窗签名"

状态：采纳（2026-11-14，S6x，用户截图驱动）
关联：ADR-100（标签条语义）、ADR-101（`∨` 下拉）、ADR-096（日志退出画面）、BACKLOG §293

## 背景

用户在实机窗口里指出三件事：**标签样式离参考图差得远**、**下拉不在 `∨` 图标下面**、
**鼠标移到下拉选项和另一个标签上会闪**。前两件是几何/观感，第三件是重画粒度：

ADR-101 把 `hover` 与面板悬停行放进内容签名 ⇒ 指针每跨一次标签边界、每跨一行面板，
下一拍就**整窗重画**（1280×800 ≈ 100 万像素的 MMIO 写，约 140 ms 级）。那就是"闪烁"。

## 决策

1. **悬停不进内容签名**。签名只保留 `(会话, 累计字节, 换行数, 标签数, 活动标签, 面板开没开)`。
   悬停变化 ⇒ 只重画标签条那一行（`bar_only`）；面板选中行变化 ⇒ 只重画面板那一块
   （`menu_only`）；两者都先 `ptr_erase`，让 `ptr_track` 用重画后的像素重新存背景。
   面板开/关仍在签名里：开要盖住正文，关要把正文铺回来，那一拍整窗重画是对的。
2. **面板从 `∨` 那一格往下开**：`menu_rect(cols, tabs, n)` 用 `BarLayout::plus_col(shown)+1`
   作左边界，越界就整体左移。绘制（`menu_panel`）与命中（`menu_hit`）共用这一份几何。
3. **标签紧挨着排**：`tab_col = strip_l + i*tab_w`（旧版多留一格 = 16 px 的缝，
   活动页右边看着空出一大截）。`plus_col` 同步。
4. 观感细节：非活动标签悬停时给一块 `#262626` 的轻底；活动页的 `×` 用亮色 `TAB_TEXT`
   （悬停到非活动页的 `×` 仍是暗色）；`+` 与 `∨` 之间加一道 1 px 分隔线（两枚图标挨着读起来像一枚）。
5. **字体资产按覆盖集重生成**：`浮窗版面` 里的 `浮`（U+6D6E）不在旧的宽字表里，
   画面把它画成空白 ⇒ 按 S6l 生成器（22px ASCII / 24px 宽字、基线对齐）重扫字面量、
   重写 `.hex` 与两张表（宽字 549 → **571** 条）。ASCII 表逐字节未变。

## 验收

- `build/s58-tabs-check.py` **九格 PASS**，其中新增两格：
  「这段里真的发生过悬停切换（防空转）」与「悬停不触发整窗重画（整画不涨）」。
  读数：`整画 1 → 1`，同段悬停切换 6 次。**负样本 N-h1**（悬停时把签名打脏）
  ⇒ `整画 4 → 10`、该格红；还原 ⇒ 绿。
- `s58-menu` 六格、`s58-keys` 八格 **PASS**（面板锚点从列 49 改到列 36，夹具同步）。
- `s6t` 11 格、`s6q` **PASS**。s6q 的 `abc^C` 判据改口径：内核日志行会**插在 shell 两次写之间**，
  先把 `[info]/[warn]/[p4]/[fatal]` 整行剥掉再找连续串（读数是"剥后仍有 abc^C"）。
- 画面取证：面板左边界 x=577 px = 第 36 格（`∨` 所在列），宽 30 格；`浮窗版面` 四个字齐全。
