# ADR-250：页缓存产品读路径重启与写一致性

状态：**已采纳并落地**（2026-11-25：`check` 22/22、完整矩阵 82/82）

关联：ADR-218（扇区缓存）、ADR-219（缓存读变体）、ADR-221（卷指纹）、ADR-238（首次回退）、ADR-241（探针信箱竞态修复）、ADR-111（覆盖写）

## 为什么可以重试

ADR-238 回退缓存不是因为锁序，而是缓存改变了读时序，放大了 ADR-228～237 的探针页回收竞态。ADR-241 已用「信箱 Mapping 归测试持有，探针回收不撤页」关闭那条竞态，并留下确定性负样本。因此本 ADR 重新启用产品读缓存，不改变 `mm` / `sched` / `trap` 的回收语义。

## 决策 1：产品句柄统一走缓存读

`ReadTicketKind::Vfs` 的 `read_chunk` 从 `read_disk` 切到 `read_disk_cached`。`read_disk` 保留为直接读参照与既有 VFS 测试路径，不删除、不改契约。

卷指纹继续在 `file_open` 时由真实盘身份与 BPB 几何算出。授句柄时再并入分区区间，形成最终缓存命名空间；整盘句柄保持原指纹不变。测试句柄也必须传真实指纹；`vol=0` 只允许出现在「不读数据」的容量格。

缓存键是 `(缓存命名空间, lba)`，粒度仍是 512 字节扇区，24 槽与 LRU 不变。分区视图的 LBA 是相对地址，若不把 `base/last` 并入键，同口不同非空分区会串缓存；空区间另由 `ensure_readable` 直接拒绝。`fs-rw` 的 `盘失败=-7` 格与 `t_vfs_cache_identity` 的产品接入格分别钉住边界与命名空间。本 ADR 不引入预读、回写或三层联动。

## 决策 2：写路径失效，且迟到填表不得复活旧扇区

启用读缓存后，`fs-rw` 的覆盖写必须与缓存一致：

1. 非整扇区写仍直接读盘做读-改-写，不经缓存，避免用旧缓存字节覆盖邻居。
2. FAT、目录项、覆盖写的每个写扇区尝试后都失效缓存；成功与失败都失效，因为失败也可能已经落下部分扇区。
3. 缓存增加单调 `generation`。未命中读盘前记下代数，读盘返回后若代数已变，本次字节仍交付调用方，但不写回缓存。
4. `cache_clear` 同样递增代数，避免清表前发起的旧读在清表后重新填回旧内容。

当前实现采用**全局失效**：一次写清掉所有卷的缓存槽。它比按 `(vol,lba)` 精确失效更保守，但实现与正确性边界更简单；24 槽规模下不引入第二套失效队列。

## 决策 3：热缓存不得掩盖设备隔离，重挂载必须换卷边界

`Block` 增加默认 `ensure_readable()`：缓存命中前先过健康闸。`AhciDisk` 在端口 `Quarantined` 时返回 `BlockError::Quarantined`；`PartitionView` 先拒 `last < base` 的空区间，再问内层设备。这样已经缓存的扇区也不会把「已隔离」读成成功。

`ReadOnlyFs::mount` 在清 dentry 的同时清页缓存。卷指纹只含盘身份与 BPB 几何，不含内容；同盘同几何换介质后，旧指纹不足以区分新旧卷。挂载是显式新卷边界，清表配合 `generation` 保证迟到旧读不会填回。代价是每次 `file_open` 都会清掉全局页缓存；本 ADR 只承诺同一打开句柄内的重复读收益，不承诺跨 open 命中。

## 锁序

`CACHE_LOCK` 继续使用 `RANK_GROW(4)`，临界区只读写静态槽，不碰设备。查表/失效都先放锁，再进入块层；AHCI `XFER` 返回后再失效，因此不存在 `CACHE_LOCK → XFER` 或反向嵌套。`lock-order.md` 补上这一条既有但未登记的叶子锁。

## 判据与负样本

- `t_fs_open_dup_shared` 增加产品路径冷/热两格：首读新增块请求，重读零新增请求且缓存命中上涨。
- `t_fs_rw_syscall23` 先证明缓存已预热，再写 `[4,8)` 并读回；写后读回必须看到新字节。同格还要求真正的空区间 `base=1,last=0` 返回 `-7`。
- 新增 `t_cache_invalidate_inflight`：夹具在未命中读盘途中调用写路径共用的 `cache_invalidate`，证明迟到旧读不会重新填表。
- 新增 `t_cache_health_guard`：夹具套真实 `PartitionView`，热读后把设备标为隔离，读必须返回 `Quarantined` 且不碰盘；同一缓存键读空区间必须返回 `BeyondPartition`。`t_ahci_recovery` 另在真实 `AhciDisk`/`PartitionView` 上验隔离映射。
- 新增 `t_cache_remount_invalidates`：同盘同几何改内容后重挂，第二次缓存读必须见新字节。
- 新增 `t_cache_failed_write_invalidates`：设备写完再返回失败，并在写调用期间填另一扇区；缓存必须失效且重读见新字节，证明失效发生在写返回之后。
- 新增 `t_vfs_cache_identity`：纯函数分别删掉分区 `base` 或 `last` 都必须红；产品接入格经 `grant_vfs_file` 授两个有效分区句柄，用同一原始 `vol` 与相同相对 LBA 读不同图案，证明不会串读。
- 负样本：产品读切回 `read_disk` ⇒ 热读格红；去掉写后失效 ⇒ 23 号内容格红；失效移到成功分支 ⇒ 失败写格红；失效移到写前 ⇒ 写期间填格被清不掉；去掉 generation 核对/递增 ⇒ 迟到填表格红；去掉健康闸、`AhciDisk` 或 `PartitionView` 健康实现 ⇒ 对应隔离格红；去掉挂载清表 ⇒ 重挂格红；分别删掉分区 `base/last` 或授句柄接入 ⇒ 身份/产品接入格对应红。
