# ADR-185：本机地址表（`IfAddr`）

状态：**已采纳**（2026-11-22：地址表、DHCP 回填、NDP 精确判属、bind 校验已落地）

关联：ADR-182（IPv6）、ADR-184（NDP 缓存，未决 1 就是本 ADR 要解决的）

> 写作纪律：每条结论标「实测」或「推断」。

## 背景

### 现状（实测）

| 项 | 现状 |
|---|---|
| 本机 IPv4 | **硬编码** `DHCP_GUEST_IP = [10, 0, 2, 15]`（`dhcp.rs:16`）|
| DHCP 结果 | `parse_dhcp_reply` 能解出 `yiaddr` / `subnet_mask` / `router`，**但不写回任何表** |
| 本机 IPv6 | 只有链路本地（由 MAC 算），**没有全局地址** |
| `handle_frame`（NDP）| 收到 NS **总是回 NA** —— 无法判断 target 是不是自己的（ADR-184 未决 1）|
| `bind` | **不校验地址归属** —— 能绑到任何地址，包括别人的 |

### 为什么必须做

三个具体后果：

1. **NDP 应答泛滥**：链路上每台机器都回 NA，真正的目标只是回得更快。
2. **`bind` 语义错**：`bind(192.168.1.1)` 在 Linux 上是 `EADDRNOTAVAIL`，我们接受。
3. **DHCP 白做**：解析出了地址却不生效，等于没有 DHCP。

## 决策

### 决策 1：地址表是「接口 × 地址」的扁平列表，不是每接口一个

```rust
pub struct IfAddr {
    pub ip: IpAddr,
    /// 前缀长度（IPv4 的 24、IPv6 的 64）。
    pub prefix: u8,
    /// 这个地址的接口号（今天恒 0，单网卡）。
    pub iface: u8,
    /// 是不是链路本地（`fe80::/10` 或 `169.254.0.0/16`）。
    pub link_local: bool,
}
```

**为什么扁平而不是 `iface -> [addr; N]`**：今天只有一张网卡，
嵌套结构要多一层索引却没有收益。等真有第二张卡时再加 `iface` 维度的查询函数即可
（字段已经在）。

### 决策 2：容量 8，**运行时分配**（按 ADR-179 的纪律）

8 × ~24 B = 192 B，放 `.bss` 完全没问题。

但**表本身用 `IrqSpinLock<RANK_NET>`**（与 socket 表、NDP 缓存同一把等级）——
因为地址表会在 `bind`（持 36 的路径）与 NDP 处理（也持 36）里读。

### 决策 3：DHCP 拿到地址后**写进表**，不再硬编码

`dhcp_apply(reply)` 做三件事：

1. 把 `yiaddr/prefix` 加进表；
2. 把 `router` 记成默认网关（另存一个字段，不进地址表——它不是本机地址）；
3. 幂等：同一地址重复 apply 不重复加。

**保留 `DHCP_GUEST_IP` 作为「夹具期望值」**：它是判据用的常量（「线上读回来的 `yiaddr` 必须等于它」），
不是「本机地址」。本机地址从表里查。

### 决策 4：NDP 应答改成**精确判属**

`handle_frame` 收到 NS 时，查地址表：`target` 在表里才回 NA，否则忽略。

**这条是本 ADR 的主要收益**：从「总是回」变成「自己的才回」。

### 决策 5：`bind` 校验地址归属

| 情形 | 结果 |
|---|---|
| 地址是 `0.0.0.0` / `::`（通配）| 接受 |
| 地址在表里 | 接受 |
| 地址不在表里 | **`EADDRNOTAVAIL`（-99）** |

**通配地址必须放行**：`bind(0.0.0.0:80)` 是「监听所有接口」的标准写法，
校验它等于让所有服务端程序失败。

## 本轮范围

| 项 | 本轮 |
|---|---|
| `IfAddr` 类型与地址表 | **做** |
| `addr_add` / `addr_remove` / `addr_lookup` / `addr_is_local` / `addr_list` | **做** |
| DHCP 回填 | **做** |
| NDP 精确判属 | **做** |
| `bind` 校验 | **做** |
| 多网卡 | 不做（字段留了 `iface`）|
| 地址生命周期（租期到期）| 不做 |

## 未决

1. **租期到期与续租**（DHCP lease time 解析 + 定时器）。
2. **多网卡**（`iface` 字段已留，查询函数要按接口过滤）。
3. **IPv6 全局地址**（SLAAC 或静态配置；本轮只加链路本地）。
4. **`addr_list` 的用户态出口**（今天只有内核侧查询，没有 syscall）。
