# ADR-141：B2 第三刀——UDP 发送与错误回执（`t_net_udp`）

状态：采纳（2026-11-18，证据来源 / 总设计阶段 B2 / 零新号）
关联：ADR-139（ARP）、ADR-140（ICMP ping）、`virtio.rs`（帧构造与解析的形状母本）、
`tools/aurora.py` 的 `filter-dump` pcap（第二台仪器）、
总设计 §阶段 B2（验收句"UDP 客户端"——本片交付 **UDP 发送侧 + 对端错误回执
的真往返**；"成功应答"那一半等一个真实监听端）

> 写作纪律：已采纳 ADR 与有测试证据的事实优先于本文的目标设计；发现冲突先记差异，
> 不要为了让文档一致去改已经验证的结论。每条结论标「实测」或「推断」。

## 背景

B2 验收句"UDP 客户端"的地基：**构造 UDP/IPv4/以太网帧发出去 + 有界等待 +
对端回执对账**。设计时想用的对端是 **slirp 的 DNS（10.0.2.3:53）**——发 DNS A
查询、收 reply。

## 实测发现（pcap 第二台仪器作证，BACKLOG §408）

**本机 QEMU 的 slirp DNS 不在线**：发 `UDP src=1053 dst=10.0.2.3:53` 的 DNS A
查询（问 localhost——不依赖外网），pcap 里包 5 显示**帧正确上线**
（`src=1053 dst=53`），slirp 回的是 **ICMP type=3 code=3（Port Unreachable）**
——同一跑里 **ICMP echo 往返（包 9/10）与 BOOTP（包 11/12）都在线**，
DNS 独缺 ⇒ **真实不归因**（推断：slirp 的 DNS 转发依赖宿主机解析可用，
与本片无关）。

**决策**：UDP 往返的判据改成 **"发送 + 对端错误回执 + 内嵌原包对账"**——
ICMP unreachable 的**内嵌部分就是我们的原包**（RFC 1122），对端用它作证
"我拒绝的是你发的那个包"：
- 内嵌原源 IP = 10.0.2.15（我们）
- 内嵌原目标 IP = 10.0.2.3（DNS）
- 内嵌原 dst 端口 = 53（我们问的端口）
**实测**：`ICMP type=3 code=3 内嵌对账=true`、PASS(33) 6.0s。
**这是真往返**（发送→有界等待→错误回执→内嵌对账），不是"发了就算"。

## 落地时撞到的三件事（实测）

1. **DNS 查询塞不进 60 字节最小帧**：eth 14 + IP 20 + UDP 8 + DNS 头 12 +
   QNAME 11 + QT/QC 4 = 69 ⇒ **帧长按内容（垫 72）**。"60 字节"模板只对
   最小帧成立，ARP/ICMP 的帧长不能照抄。
2. **UDP 源端口 0 会被 slirp 拒**：初版源端口写 0（任意），pcap 证明
   slirp 回 Port Unreachable——**<1024 是特权号**。改 `DNS_QUERY_PORT=1053`
   （非特权）。（回执类型不变——不可达照旧——所以这一格要靠内嵌对账分辨。）
3. **RX 缓冲里收到的包不保证是"发给我们的下一个"**（`.ktests` 自足纪律的
   网络版）：同一跑里 ping 的残留包会被本用例收走，偏移彻底不同
   （实测先收一个 `0x45` 开头的无 eth 头残包）。**修法**：用**首字节判断
   偏移基准**（`buf[0]==0x45 ⇒ 无 eth 头`）——判据不假设队列干净。
   **教训**：网络用例与 `t_timer` 一样必须对"队列里有什么"零假设。

## 判据（`t_net_udp` 四格）

①ARP 往返（解网关 MAC——DNS 在别的子网，帧走网关）②UDP 帧上线（TX 回执；
pcap 那一格是判定表既有行）③**收到 ICMP type=3（错误回执）**④**内嵌原包
对账**（三字段）+ used_id=0（缓冲对）。

## 影响

正面：**UDP 发送侧全链路**（帧构造→上线→回执→内嵌对账）；`NET_DNS_IP`/
`DNS_QUERY_PORT` 常量族就位（真正的 DNS 解析器是下一片，等 slirp DNS
可用的环境或自建对端）；ICMP 错误消息的解析器接缝（type/code 分派）。

负面：**没有"成功应答"的 UDP 往返**（本机无在线 UDP 对端；`parse_dns_reply`
已就位但判据未用）；ARP 表仍没有（每帧广播）；DNS 报文只构造到查询，
解析 answer RDATA 未做。

## 验收与负样本

- `t_net_udp` 四格，virtio-net 档全绿 PASS(33) 6.0s（实测）。
- **变异证红**：内嵌端口期望 53→9999 ⇒ FAIL(35)；还原 ⇒ 绿（实测）。
- `check` 18/18；整链 69/69 rc=0。

## 迁移与回滚

零新号、零既有判据改动。回滚 = 删 `build_dns_query`/`parse_dns_reply`/
`t_net_udp` 三块 + `DNS_QUERY_PORT` 常量。

## 未决

1. **"成功应答"的 UDP 往返**：需要在线 UDP 对端（自建用户态 echo 服务 /
   QEMU 加 `-netdev` 选项 / 真机），或 slirp DNS 可用的环境。
2. **ARP 缓存**：每一帧都先广播 ARP——**表 + 老化**是下一步的必修。
3. **payload 回环校验**（ADR-140 未决 3）仍开。
