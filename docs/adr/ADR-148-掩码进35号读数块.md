# ADR-148：掩码进 35 号读数块——去掉 shell 的硬编码（零新号）

状态：采纳（2026-11-18，证据来源 / 总设计阶段 B2 / **零新号**）
关联：ADR-143/144（33/34/35 号三原语与读数块）、ADR-147（路由判据，
未决 1 点名本片）、总设计 §阶段 B2

> 写作纪律：已采纳 ADR 与有测试证据的事实优先于本文的目标设计；发现冲突先记差异，
> 不要为了让文档一致去改已经验证的结论。每条结论标「实测」或「推断」。

## 背景

ADR-147 的用户态路由判据里有一处硬编码：

```rust
let mask: [u8; 4] = [255, 255, 255, 0];
```

内核侧 ADR-147 已经把掩码作为 `NET_SUBNET_MASK` 常量（来路是
`-netdev user,net=10.0.2.0/24` 的启动参数，与 `DHCP_GUEST_IP` 同源，
**不是猜的**），但用户态拿不到——35 号读数块停在 24 字节，没有掩码位。
ADR-147 未决 1 明确写了"扩 35 号到 28 字节加 mask4"。

## 决策

### 决策 1：35 号读数块 24 → 28 字节，尾部加 mask4

```
偏移 18..20  mtu（u16 小端）
     20..22  link（u16 小端）
     22..24  预留（8 字节对齐）
     24..28  子网掩码（4）
```

写入的是 `virtio::NET_SUBNET_MASK`——**同一个常量**内核路由判据和用户态都用，
从此不再有两份"看起来一样"的掩码。

### 决策 2：DHCP option 1 动态替换留到下一片

`parse_reply` 在 ADR-147 已经解析 option 1 到 `Reply.subnet_mask`，但那个值
只存在于 `t_net_rx` 的局部变量里，没进全局 NetInfo。本片**不引入全局可变配置**
（那会让 `ip link` 依赖"ktest 是否先跑过"这种脆弱顺序），
而是把"显式常量"作为唯一来源。动态覆盖是后续独立决策。

### 决策 3：`ip route` 显示掩码前缀，作为本片的可判据出口

```
route default via 10.0.2.2 mask=24
```

前缀长度按掩码**从高位到低位连续 1 的个数**算（`255.255.255.0 → 24`），
逐 bit 数、每字节 `get()` 取值——不索引、不取址（32S 纪律）。

判定格 `_ip_route_row` 随之收紧：`route default via <IPv4> mask=<0..32>`。
**不依赖具体前缀 24**（换 QEMU 网段也成立），只验形状与合法范围。

## 落地时撞到的事（实测）

1. **我的 Python 写入又把四个文件写成双重编码**（`user.rs` 160 处、
   `virtio.rs` 287、`registry.rs` 57、`runtime/lib.rs` 69）。
   按行 `latin-1 → utf-8` 逆转清零。**这是本会话第 N 次同类错误**——
   根因是把中文写进 `b'...'` bytes literal 失败后改用 `.encode('utf-8')`
   又在已经编码的文本上再编码一次。
2. 第一次尝试用 `b'...中文...'` 写内核块 ⇒ `SyntaxError: bytes can only
   contain ASCII literal characters`（这是老教训，ADR-137 就记过），
   改用 `read_text` / `write_text` 才过。
3. `check-module-interfaces` 报 `NET_SUBNET_MASK` 未登记 ⇒ 补进白名单。

## 验收与负样本

**实测**（a3-shell，PASS(33) 15.0s）：

```
ip route
route default via 10.0.2.2 mask=24
```

`ping` 往返、`ip neigh` 表项都保持正常（掩码从 35 号读，路由判据形状没变）。

**变异证红**：删掉 `ip route` 里的 `mask=` 显示 ⇒ 整链
`A3 shell执行argv命令并ps/free读数: CONTENT-MISMATCH`；还原 ⇒ 绿（实测）。

`check` 18/18（编译接口白名单 +1）。

## 影响

正面：掩码只有一份来源（内核常量），shell 不再硬编码；`ip route` 给出可判据的
前缀形状；35 号读数块结构稳定在 28 字节。

负面：**掩码仍是静态的**（DHCP option 1 学到但没用）；用户态和内核仍各有一份
`is_local_subnet` 实现（ADR-147 的取舍，靠共同常量与 ktest 作证）。

## 迁移与回滚

零新号。回滚 = 35 号块回 24 字节 + runtime `NET_INFO_BYTES` 回 24 +
shell 掩码恢复硬编码 + `ip route` 去掉 `mask=` + 判据放宽。

## 未决

1. **DHCP option 1 动态覆盖**：需要一个全局配置槽 + "谁先写"的顺序约定，
   单独 ADR。
2. **TCP 三次握手**：B2 剩下的最大项，单独 ADR。
