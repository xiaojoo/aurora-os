# ADR-184：NDP 邻居缓存与收包投递

状态：**已采纳**（2026-11-22：缓存、收包投递、recvfrom 已落地；中断收包见未决）

关联：ADR-181（socket 族）、ADR-182（IPv6）、ADR-183（socket 双栈，决策 4 的妥协在本轮被替换）

> 写作纪律：每条结论标「实测」或「推断」。

## 背景

### 两个真实缺口（都在上一轮自己标出来的）

| # | 缺口 | 出处 |
|---|---|---|
| 1 | **`socket::enqueue` 没有任何调用者** —— 收了包不会进队列，`recv` 永远回 EAGAIN | ADR-181 |
| 2 | **IPv6 的目标 MAC 用组播兜底**，没有 NDP 邻居缓存 | ADR-183 决策 4 |

第 1 条是最严重的：**整个 socket 的接收方向是断的**。ADR-181 建了队列，
但没有任何代码往里放东西。`t_socket_family` 只验了「空队列回 EAGAIN」——
那恰好掩盖了这个缺口（空队列永远回 EAGAIN，所以判据绿）。

## 决策

### 决策 1：收包投递用**轮询**，不进中断

`virtio::receive(wait_ms)` 今天就是轮询式的。改成中断要动 `RANK_NET` 的
「是否在 ISR 取」那一格（`lock-order.md` 写明是「否」），那是另一件事。

`socket::poll_once(wait_ms)` 在 **syscall 上下文**调，一次最多处理 8 帧
（队列深度就是 8，超过没意义）。

### 决策 2：`deliver_frame` 按协议分发，**NDP 优先于 UDP**

```
IPv6 帧 → next header == 58（ICMPv6）？ → 是：处理 NDP，回 NA（锁外），返回
                                       → 否：解析 UDP，投递到队列
IPv4 帧 → 解析 UDP，投递到队列
```

**NDP 必须先判**：它是 ICMPv6，不走 UDP 解析。混在一起会让 NDP 帧被当成坏 UDP 丢掉，
然后邻居永远学不到 MAC。

### 决策 3：NDP 缓存与 socket 表**共用一把锁**（`RANK_NET = 36`）

两者都是「网络层的小表」，且**从不互相嵌套获取**。共用的好处是
「查表 → 发包」这一串只有一个锁等级要维护。

### 决策 4：缓存只做 `Incomplete` / `Reachable` 两态

RFC 4861 §7.3.2 有五个状态（另加 STALE/DELAY/PROBE）。
那三个是为了「邻居悄悄换了 MAC」的检测，**需要定时器与再确认逻辑**——本轮没有。

**`Incomplete` 不算命中**：那个槽只是「我们正在问」，还没有答案。
这一条有负样本（见下）。

### 决策 5：`send` 三级回退

| 级 | 条件 | 动作 |
|---|---|---|
| 1 | 缓存命中 | 单播，最高效 |
| 2 | 缓存未命中 | **同时**发 NS（去问）+ 本帧走组播 |
| 3 | 下一帧 | 命中缓存 |

**第 2 步为什么既发 NS 又发数据**：严格按 RFC 4861 应该等 NA 回来再发，
但那要阻塞几十毫秒，而 `send` 是非阻塞语义。折中是同时发——
NS 让对端回 NA 填缓存，数据帧走组播仍然能到（目标主机一定在自己的组播组里）。

**第一帧多绕一圈，第二帧起就是单播。**

### 决策 6：`recv` 支持 `recvfrom` 语义

`r10` = 源地址输出指针（0 = 不要），`r8` = 超时 ms（0 = 非阻塞）。

**为什么用 r10/r8 而不是 rcx/r9**：SYSCALL 会覆盖 rcx（返回地址），
而 Linux 的 syscall ABI 本来就把第 4 参放 r10。

## 本轮范围

| 项 | 本轮 |

| `ndp` 邻居缓存（lookup/learn/mark_incomplete/stats/clear）| **做** |

| 中断收包 | 未做 |

## 未决

1. **本机地址表**：`handle_frame` 收到 NS 时**总是回 NA**，因为无法判断 target 是不是自己的。
   代价是链路上每台机器都回，真正的目标回得更快。有地址表后可以精确判。
2. **中断收包**（把 `poll_once` 换成 ISR 驱动，需要改 `RANK_NET` 的 ISR 属性）。
3. **STALE/DELAY/PROBE**（邻居换 MAC 的检测）。
4. **`sin6_scope_id`**（链路本地地址需要 scope 才能唯一定位接口，本轮忽略）。
