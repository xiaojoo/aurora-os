# ADR-192：对象引用计数（`close` 减引用，最后一条才销毁）

状态：**已采纳**（2026-11-22：socket 引用计数落地，`sockref` 七格全 true）

关联：ADR-191（句柄 owner 认进程）、ADR-186（fd 号段）

> 五样对象化第二片（B）。

## 背景：引用计数**不统一**

先测量现状（这是本 ADR 的第一步，不是先动手）：

| 对象 | 有引用计数吗 | 谁管 |
|---|---|---|
| VMO | **有**（`refs: u16`）| `vmo_ref`/`vmo_unref` |
| File / VfsFile | **有**（共享游标格子）| `cell_retain`/`cell_release` |
| **Socket** | **没有** | `sys_sock_close` 无条件 `destroy` |
| Console | 不需要（内核静态对象，无销毁路径）| — |

### 为什么 Socket 缺是致命的

```
fd1 = socket()
fd2 = dup(fd1)
close(fd2)       // ← 本体被销毁
send(fd1, ...)   // ← 这条还活着的名字悬空
```

`sys_sock_close` 里那句 `crate::network::socket::destroy(slot, gen)` **无条件**执行，
不管还有几条名字指向它。

## 决策

### 决策 1：`Socket` 加 `refs: AtomicU32`

`create` 时置 1（出生就有一条名字）。

### 决策 2：`dup` 加引用、`close` 减引用，减到 0 才销毁

```rust
pub fn sock_ref(slot, gen) -> bool      // dup 时调，加一
pub fn sock_unref(slot, gen) -> bool    // close 时调，减一；返回 true = 本体已销毁
```

`sock_unref` 里：

```rust
let prev = s.refs.fetch_sub(1, AcqRel);
if prev > 1 { return false; }   // 还有别的名字活着
// 最后一条：真的销毁
s.refs.store(0); s.used.store(0); ...
```

### 决策 3：`dup` 里 Socket 与 VMO 同一位置加引用

两者都是「本体住旁表、句柄只是名字」的 kind。加引用在**锁外**（`sock_ref` 要取 `RANK_NET(36)`），
提交失败在锁外退回。这与 VMO 的 `vmo_ref` 完全同构。

## 判据七格（`t_socket_refcount`）

```
sockref: 基线=0 dup两条=true 关二后一可用=true 本体在=true
         关二没销毁=true refs=1 关一后本体没了=true 收场=0 ⇒ true
```

**`refs=1` 是关键读数**：关掉第二条名字后引用数从 2 减到 1，本体仍在。

## 负样本（变异证红）

把 `if prev > 1 { return false }` 改成 `if false && prev > 1`：

```
sockref: 关第二条就把本体销毁了（引用计数没生效）
sockref: 关第二条之后第一条失效 closed2=true h1可用=true 本体在=false
```

**FAIL(35)。** 判据精准咬住。

## 三个实测撞出来的坑

**① 测试只调 `handle::close`，永远测不到引用计数**

`sys_sock_close` 做的是「`handle::close` + `sock_unref`」两步。
第一版测试只调第一步 ⇒ `本体没了=false`，那是**测试的错**，不是实现的错。

**② `OpenSpinLock` 的 `INNERMOST` 记账在 CAS 之前**

竞争失败时不还原 ⇒ 下一次取同一把锁看到 `外层 rank=37 本次 rank=37` ⇒ **EXCEPTION(39)**。

修法：记账移到 CAS **成功之后**，且判据要排除 `prev_rank == 0`（0 表示「没有外层锁」不是违规）。
`OpenGuard` 记住 `prev_rank`，Drop 时**还原成它**而不是无条件清 0。

**③ `OpenSpinLock` 缺 `Sync` 实现**

`static XFER: OpenSpinLock<()>` 编译失败 `UnsafeCell<()> cannot be shared`。
照 `IrqSpinLock` 补 `unsafe impl Sync`，并写 SAFETY 注释（`check-unsafe` 要求）。

3. **Console 无销毁路径**（不需要，但要记明）
