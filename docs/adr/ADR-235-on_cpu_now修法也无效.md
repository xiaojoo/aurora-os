# ADR-235：`on_cpu_now` 修法**也无效**（第二次修法失败，已回退）

状态：**拒绝**（2026-11-23：实施后 3/20，与修复前相同，已回退）

关联：ADR-230（修法 A）、ADR-231（A 无效）、ADR-234（`gi` 确认是探针）

> ADR-234 给了方向：「`reap` 需要一个『这个槽还站在 CPU 上』的判据」。
> 本 ADR 实施它 —— **仍然无效。**

## 实施内容

`terminate_task` 里原来**无条件**置 `Free`（第 358 行）。改成：

```rust
s.tasks[slot].state = if s.current == task {
    TaskState::Done      // 还在 CPU 上
} else {
    TaskState::Free      // 已经不在
};
```

理由：`reap` 的 `gi == cur` 闸只在 `cur` 还是它时生效；置 `Done` 让它在「还在 CPU 上」
这个语义上更准确。

## 结果：3/20，与修复前完全相同

**但观测证实改动**生效了**（`Done` 计数这次跟着涨）：**

```
回收=18→19(Done=18→19)
末次回收gi=2→2(含容器=false→true) 探针gi=2
容器段撤映射=0→2 容器段owned=0→1(slot=→2)
reap挡住=25→26
```

## 为什么仍无效：**回收与挡住是两次不同的事件**

关键读数：`reap挡住=25→26`（挡住 **1** 次）、`回收=18→19`（回收 **1** 次）、
**两者的 `gi` 都是 2**。

```
第 N 次 reap:  gi=2, cur=2  => gi == cur => 挡住（+1）
第 N+M 次 reap: gi=2, cur≠2  => 通过     => 回收（+1）
```

**所以「挡住」和「回收」不是同一次 `reap` 里的两个分支，而是两次不同的 `reap`。**

在第 N+M 次时 `cur != 2` —— 也就是说，**探针已经不在 CPU 上了**（至少 `current_of` 这么说）。

## 这暴露了真正的问题

**`current_of(cpu)` 与「这个任务是否还在执行」是两回事。**

`exit_current` 之后：

1. `mark_need(cpu)` 立牌；
2. `iretq` 回到用户态；
3. 探针继续 `loop { SYS_EXIT }`；
4. 下一个 tick 或 syscall 抢占点 ⇒ **换人** ⇒ `current_of` 变成别人；
5. 但探针的**用户态代码还在跑**（它只是被换下，不是被销毁）。

**「被换下」= 不在 CPU 上 = `reap` 认为可以回收。而它其实还会被换回来继续跑。**

所以 `on_cpu_now` 这个判据（`s.current == task`）**本来就只反映「此刻在不在跑」**，
而不是「还会不会再跑」。

## 真正的修法应该是什么（第三个候选）

`reap` 不该回收一个**状态仍是可调度**的任务。而现在：

- `terminate_task` 把它置 `Free`/`Done`（都不可调度）；
- 但它在用户态还会继续执行到下一次 `SYS_EXIT`。

**矛盾在于：`SYS_EXIT` 返回了，任务却还活着。**

正确方向应该是 **`SYS_EXIT` 不返回**：

```rust
// 现在（sched/user.rs:4705）
SYS_EXIT => { record_exit_code(...); exit = true; 0 }
// exit = true => trap.rs:1132 => exit_current => 返回 => iretq => 用户态继续跑
```

**`Action::Exit` 的语义应该是「不再回到用户态」，而不是「回到用户态但标记退出」。**

但那要改 trap 出口（跳到一条内核落脚页，像 `park_current` 那样），
**属于改已实测的中断/异常语义**，需要单独一轮。

## 两次修法失败的共同点

| 修法 | 改了什么 | 为什么无效 |
|---|---|---|
| A（ADR-231）| 置 `Done` | `has_bag` 的 `\|\| st == Done` 让 `Done` 更容易被收 |
| B（ADR-235）| `on_cpu_now` 时置 `Done` | 「挡住」与「回收」是两次不同 `reap`，`cur` 那时已变 |

**两次都在改「状态字段」，而问题在「`SYS_EXIT` 会返回」。**
