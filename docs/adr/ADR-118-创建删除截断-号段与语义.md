# ADR-118: 创建 / 删除 / 截断（号段裁决与语义）

状态：**采纳**（使用者裁决 2026-11-18：**新开号**；实现未开始，本文关于新行为的句子均为推断）
关联：ADR-106（号段/错误码）、ADR-107（只读第一刀）、ADR-108（句柄）、ADR-110（块层）、
ADR-111 决策 4（创建/截断/扩展另开 ADR）、ADR-132（27/28 已被 A4 占走）、BACKLOG §402

## 背景

ADR-111 决策 4 把创建 / 截断 / 扩展留给另一份 ADR。今天写方向只有 23 号"覆盖已有区间"：
不能创建新文件、不能缩短、不能删除。使用者要在 shell 上做 `cmd1 | cmd2`（shell 级管道，
用可写卷上的临时文件中转），前提是"能创建与删除一个临时文件"。

## 号段（裁决：新开号）

- **30 `truncate(h, new_len)`**：沿用 ADR-106 号段表里的预留项；**只缩不扩**，
  `new_len > size` ⇒ `-1`（`EINVAL`，一个字节都不动）。扩展仍属"另一刀"。
- **34 `create(path) -> handle`**：**新号**（ADR-106 的表里没有它；那是"open+O_CREAT"的位置）。
  空文件（size 0、首簇 0），返回带 `RIGHT_READ|RIGHT_WRITE` 的句柄。已存在 ⇒ `-17 EEXIST`
  （新增错误码，见下）。**只支持 8.3 短名**；带长名或含非法字符 ⇒ `-1`。
- **35 `unlink(path)`**：**新号**。链上仍有打开的句柄 ⇒ `-16 EBUSY`；成功 = 目录项首字节
  置 `0xE5` + 释放簇链（两份 FAT）。
- 29（rename）/31（fsync）/32（mount）/33（umount）**保持预留，不动**。
- **勘误记录**：ADR-106 号段表里 27=mkdir、28=unlink 是"未批准逐号"的建议；27/28 已在
  ADR-132 被使用者批给进程观测（`proc_enum`/`proc_stat`）。因此 `unlink` 顺延到 **35**，
  `mkdir` 仍无号、不在本刀。

## 错误码

- 新增 **-17 `EEXIST`**（`create` 打到一个已存在的名字上）。`-14 EROFS` 用于只读卷，
  `-15 ENOTSUP` 用于"这块卷/这份构建不支持写"，`-16 EBUSY` 用于删除打开中的文件。
- 设备失败一律 `-7 EIO`（ADR-108 补记六），不把 `ENOSPC` 抹成 `EIO`：
  簇耗尽回 **-10 `ENOSPC`**（ADR-106 已列）。配额（每卷/每进程簇上限）今天没有，先按"整卷满"算。

## FAT32 写语义（实现约束）

1. **只写可写卷**（`fs-rw` 的口 4，ADR-111 决策 3 的现算夹具）；只读卷上三号一律 `-15`。
2. `create`：在目标目录里找一个空槽（`0x00` 项，或 `0xE5` 可复用项）；写一条 8.3 短名目录项
   （attr=0x20、首簇 0、size 0、时间戳取卷内已有约定的"合成时间"，ADR-107 §6）。目录项满 ⇒ `-10`。
3. `unlink`：目录项首字节 `0xE5`；沿链把**两份 FAT** 的项清 0。链上句柄未关 ⇒ `-16`。
4. `truncate`：新长度按簇取整后释放尾簇（两份 FAT 清 0、最后一簇置 EOC），
   改目录项 size；新长度为 0 时首簇归 0。链坏（循环、越界）⇒ `-7`，且**不改任何东西**
   （先走链验证再落笔）。
5. **FSInfo 的空闲簇计数不更新**，这是本刀的已知欠账：它是提示值，不参与任何判据；
   宿主机对账只认目录项与 FAT 本身（`fat32_host_volume` 那份独立解析）。
6. 长名创建（LFN 组项、校验和、序号）不在本刀；`create` 拒绝非 8.3 名。

## 判据

- ktest（`fs-rw` 档）：`create` 后立刻 `stat`（size 0）→ 写入 → 读回；`truncate` 到一半 →
  读回只剩前缀、`stat` 尺寸对；`unlink` 后 `open` 回 `-8`。负样本：重复 `create` ⇒ `-17`；
  `unlink` 打开中的文件 ⇒ `-16`；`truncate` 超长 ⇒ `-1` 且盘上零改动。
- 宿主机：跑完解析 `build/fat32-rw.img`——新建的名字在目录里、大小对、删除的名字不在了、
  被 truncate 的文件簇链短了；**改动只许落在该落的簇/目录扇区**（其余字节与配方逐字节相同）。

## 没做到的

- 扩展（写越过 EOF 分配新簇）、mkdir、rename、长名创建、FSInfo 计数、配额；
- shell 级管道（`cmd1 | cmd2`）依赖本刀的 create/unlink，本 ADR 落地后另开一刀。
