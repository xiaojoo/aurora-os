# ADR-099：浮窗拖动——按住态轮询、旧矩形并集还原

状态：采纳（2026-11-14，S6w，#57）
关联：ADR-091（屏幕指针与点击命中）、ADR-095（浮动窗口与每扇只画自己的矩形）、
ADR-097/098（会话关闭与重开）、BACKLOG §285

## 背景

浮窗只能"点标题置顶"，不能挪。而且一旦挪动，**旧矩形没人负责**：桌面底色只在
`open()` / 桌面结构变化时整屏重铺一次，窗口自己的矩形之外没有任何绘制者。

## 决策

1. **鼠标暴露"按住态"**：新增 `mouse::buttons() -> u8`（bit0 = 左键）。
   理由：点击事件只在**按下沿**发一次（`take_click`），拖动的中间帧没有事件可用，
   只能轮询按键状态。这是既有 ISR 里那个 `BTNS` 原子量的只读访问器，零新状态。
2. **拖动 = 按下标题开始、每拍轮询**：`LiveTerm.drag: Option<(窗口, 抓取列差, 抓取行差)>`。
   抓取差是"指针格 − 窗口原点"，所以窗口跟着指针走而不是把标题格吸到指针上。
   位置按格夹在屏幕内（`cols - w.cols`）。
3. **旧矩形用"并集"记，不能只记最后一次**：`drag_step` 每拍跑、`repaint` 每 8 拍一次，
   只存一个格子的话中间那些移动的旧矩形会被覆盖——**实测** 7 次移动只铺回了最后一个
   `(5,8)`，第 1 行的旧标题条原样留在屏上。改成与历史位置求并集后，一次铺
   `(1,1,74,18)` 覆盖整条轨迹。
4. **移动只进"桌面签名"的第三格**（`mvseq`），与"结构变了"分开：
   结构变（开着的窗 / 版面）⇒ 整屏 `clear` 再画栈；**只是挪了位置** ⇒ 只把旧矩形并集
   铺回桌面底色、再画栈。这样拖动不会每拍整屏重铺（那是 S6u 才拆掉的代价）。
5. 松开（`buttons() & 1 == 0`）结束拖动并打一行 `wm: 拖动结束 窗口=… 位置=(…)`。

## 验收与负样本

`build/s57-drag-check.py`（`wm,ps2-kbd,ps2-mouse,resident-init,console-probe`）：
一次手势"按下标题 → 按住移到 (14,9) → 松开"。判据：

· 反空转：拖动前第 1 行**确实**是标题条（`#333333` > 500）；
· 串口有 `wm: 拖动` 与 `wm: 拖动结束`；
· **旧矩形还原**：第 1 行（旧标题条）`#333333` 计数 = **0**；
· 新位置（第 9 行、列 5..75）`#333333` > 500；
· 三张画都落盘。

**实测**：`wm: 铺旧矩形 旧=(1,1,74,18) 视图=true`、旧行 `0`、新行 `35013` ⇒ **PASS**。
负样本（手动）：把 `else if moved { … }` 整段注释掉 ⇒ 旧行仍是 35061 ⇒ "旧矩形还原"变红；
只存最后一次（第一版）同样红——这两个都跑过，红因不同、都指向同一格。
