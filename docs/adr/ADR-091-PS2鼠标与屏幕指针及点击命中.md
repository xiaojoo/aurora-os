# ADR-091：PS/2 鼠标与屏幕指针——IRQ12、状态位分流、几何箭头与命中测试

状态：已采纳（2026-11-13，S6o 实测 / BACKLOG §259）
关联：ADR-084（键盘并入 21 号）、ADR-088/089（终端样式、标签栏）、ADR-090（换入用户任务强制开窗）

> 写作纪律：已采纳 ADR 与有测试证据的事实优先于目标设计；每条结论标「实测」或「推断」。

## 背景

标签栏上的 `×`、`+` 与窗口按钮画好了，但**没有指针、没有点击**，它们只是装饰。
本片补上鼠标：i8042 第二口 + IRQ12 + 3 字节包解码 + 屏幕几何箭头 + 命中测试打日志。

## 决策

1. **命令字节必须写（与键盘相反）**：本机读回 `0x67`（`ATT1|AUXDIS|IGNKEY|KBDINT`）
   ⇒ 鼠标口是**关的**（bit5=AUXDIS=0x20）、鼠标中断也没允许（bit1=AUXINT=0x02）
   ⇒ 写成 `0x47`，然后**用 0x20 读回核对**（写命令字节那一步的回包是实现相关的，见决策 2）。
2. **只等"设备"的 ACK，不等"控制器"的**：本机 QEMU 对 `0x60`（写命令字节）与 `0xD4`
   （下一字节写给 aux）**都不回包** —— 两处按"等 ACK"写都会 20 ms 后 `PortTimeout`（实测两次）。
   现在的形状：写命令字节后**读回核对**；`0xD4` 之后排掉可能的杂字节，判据放在**设备**
   对 `0xF6`/`0xF4` 的 `0xFA` 上。每一步用不同的错误变体（`WriteDenied(0x20/0x21/0xD4/0xF6/0xF4)`），
   出问题一眼看得出停在哪。
3. **0x60 共用 ⇒ 按状态位 bit5 分流**：`in8(0x64)` 的 bit5 说这个字节来自鼠标口。
   **键盘 ISR 只吃 bit5=0、鼠标 ISR 只吃 bit5=1**。不做这件事的表现很有欺骗性：
   指针第一下能到位、之后丢包（键盘 ISR 把鼠标包当扫描码吃了）——实测就是这样。
4. **指针用几何画**：7×11 的箭头（`#` 填充、`o` 描边），`draw_pointer` 在终端重画之后叠上去；
   下一帧整屏重画会把它擦掉 ⇒ **不需要"保存/恢复背景"那套簿记**。位置在初始化时放屏幕中心。
5. **点击的记录在 ISR、打印在任务上下文**：ISR 只写 `CLICK_PENDING` 与坐标；打印放在
   `LiveTerm::repaint`（两个等待循环都会路过它 —— 只在常驻循环里取会漏掉**等待期**的点击，实测）。
6. **命中测试与绘制共用同一份几何**（`BarLayout`）：两处各算一遍，点击就会落在画的地方旁边。
   命中项：标签关闭 / 标签 / 新建标签 / 最小化 / 最大化 / 关闭窗口 / 标签栏空白 / 终端正文。

## 备选方案

- **在 ISR 里打印点击**：串口行锁不能在 ISR 里拿（与键盘同一条纪律）。
- **用鼠标走绝对坐标（QMP `abs`）**：PS/2 是相对设备；判据改成**位移可复算**（+120 ⇒ x+120，±2）
  才是这类设备能验的东西。第一版按"屏幕中心+120"断言绝对落点，实测对不上。
- **给指针做"保存背景再恢复"**：整屏重画本来就要发生，重叠一次更简单。

## 影响

正面：标签栏的控件第一次**点得着**（点击会打一行 `mouse: 点击 x=… 命中=…`）；指针随手移动。
负面/代价：**点击今天只产生读数，不产生动作**——只有一个会话可关、`+` 没有第二个会话可开、
最小化/最大化没有窗口管理器（如实记在未决）；指针每帧重画 ⇒ 常驻轮询从 32 窗口降到 8 窗口
（约 0.12 s 一轮），光标闪烁因此改成按帧数除（每 4 帧翻一次）。
基线影响：`input` 逻辑模块新增 `mouse` 源模块（环外单向边，与 `kbd` 同家）；
`display.public_api` 增 `fbcon::hit_test`；unsafe 白名单不变（鼠标零 unsafe，端口读写复用 `serial::in8/out8`）。

## 验收与负样本

判据（`build/s6o-mouse-check.py`，features=`fbcon-live,ps2-kbd,ps2-mouse,resident-init,console-probe`）：
`mouse: 已开 IRQ=12 命令字节=0x67->0x47 设备ACK=0xFA`、三帧都看得到指针、
`+120 ⇒ x 增加 120（±2）`、`移动不改变 y`、`反空转：基准帧与移动帧位置不同`、
`-120 ⇒ 回到基准 x（±2）`、`mouse: 点击 x=280 y=16 命中=标签关闭` ⇒ **判定=PASS**。
**负样本**：把 `draw_pointer` 的调用去掉 ⇒ `三帧都看得到指针` 红、判定=FAIL；还原后 PASS。
回归：默认/`handles`/`ps2-kbd,handles`/`framebuffer,handles` 四档全 PASS(33)。

## 迁移与回滚

无接口迁移。回滚 = 去掉 `ps2-mouse` 特性（`mouse.rs` 与 `draw_pointer`/`hit_test` 一起不编译）。

## 未决

1. **点击只出读数、不出动作**：`+`/最小化/最大化都还没有语义（没有多会话、没有窗口管理器）；
   标签关闭也不真关（只有一个会话）。
2. **没有指针形状变化**（悬停在按钮上不变手形）、没有拖拽、没有双击。
3. 常驻轮询 8 窗口 ⇒ 指针仍有约 0.12 s 的跟随延迟；真正的跟手要么在 IRQ 里做局部更新
   （保存/恢复背景），要么上中断驱动的重画节流。
4. 相对位移在 QEMU 侧会被拆包/合并（实测按绝对落点断言对不上）；判据只能用位移。
