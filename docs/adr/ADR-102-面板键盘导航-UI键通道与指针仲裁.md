# ADR-102：面板键盘导航——UI 键通道与指针/键盘仲裁

状态：采纳（2026-11-14，S6w 第四刀）
关联：ADR-101（`∨` 下拉面板）、ADR-100（标签条语义）、BACKLOG §291

## 背景

ADR-101 把"面板里没有键盘导航"列进"本片不做"。用户裁决继续做。难点有三处：

1. **方向键今天到不了任何地方**：`E0 48` / `E0 50` 在 `kbd::step` 里归 `ExtTail`（"吃掉"），
   既不进 64 格字符环，也没有别的出口。直接把它们改成 `Char(u8)` 会**污染 shell 的输入**
   ——用户按 ↑ 就会往命令行里塞一个控制字节。
2. **Esc / Enter 已经是 shell 的输入**：两者本来就走 `Char` 进环，shell 靠 Enter 提交命令行。
   面板开着时它们必须**归面板**，但不能改变"面板没开时 Enter 仍然提交命令"这条语义。
3. **两路输入会互相踩**：ADR-101 的悬停是"每拍按指针位置算 `menu_hover`"。
   键盘选中一行之后指针没动，下一拍悬停又会把它算回 `None` 或指针下面那一行。

## 决策

1. **kbd 增加一条给 UI 的旁路**：`Code::Ui(u8)` + 单一槽 `UI_KEY` + `kbd::take_ui_key()`。
   方向键 `E0 48/50` 解成 `Ui(0x80/0x81)`，**不进字符环**；面板没开时每拍丢弃。
   单一槽而不是队列：面板一拍取一次（约 16 ms），连按丢一次方向键无害；
   做成队列就要为它扩账目，收益不成比例。
2. **Esc / Enter 走"模态捕获"**：`kbd::set_ui_capture(on)` 是一个归属开关，
   UI 每拍把它同步成"面板开着吗"。捕获期间 ISR 把 `0x1B` / `0x0D` 交给 UI 槽、
   **不进 64 格字符环**；面板关着时它们照旧进环、由 shell 取，Enter 提交命令的语义一字不变。
   **不碰 `serial::read_byte()`**——它的注释写着"只供一个任务消费者调用"，
   面板不是那个消费者。**这也是一处被实测纠正的设计**：首版让 `menu_keys()` 直接读
   `kbd::read_char()`，与 shell 抢同一个环；实测第二段（切到会话 1 之后 shell 就读那个环了）
   Esc 被 shell 抢走 ⇒ `Esc 关=False`、面板残留 56247 px ⇒ 改成捕获后八格全绿。
   账目口径不动：捕获走掉的字节仍记在"吞掉"格（与它从前当 `ExtTail` 时同格），
   `字节 = 入环 + 丢弃 + break + 扩展 + 吞掉 + 不映射` 这条等式不用改。
3. **指针与键盘的仲裁按"指针动没动"**：新增 `last_ptr`，只有指针位置变了才用
   `menu_hit` 覆盖 `menu_hover`；指针不动就保留键盘选中的行。
   关掉面板时把 UI 槽清空，免得下次开面板先"补跳一格"。
4. **Enter 执行 `menu_hover` 那一行，没有选中时执行第 0 行**。执行走的是与鼠标点击
   **同一个函数** `menu_run(row)`——两个入口各写一份动作表，迟早会分叉。
   置灰行仍然如实报容量墙，不假装成功。
5. 接口登记：`kbd::take_ui_key` 进 `input.public_api`；`Code::Ui` 是 `kbd` 内部的枚举变体，
   不进公开面。

## 验收

`build/s58-keys-check.py`（档 `wm,ps2-kbd,ps2-mouse,resident-init,console-probe`，八格）：

- 点 `∨` ⇒ `菜单: 开=true`；
- 按 ↓ ⇒ `菜单: 行=1`；
- **指针停着不动**按 Enter ⇒ `菜单: Enter 行=1` **且** `菜单: 切到会话 1 ⇒ 关`
  （第 0 行的动作是"切到会话 0"，所以这一格同时咬住"选中行不是默认第 0 行"；
  若悬停把选择盖回 `None`，读数会变成 `Enter 行=0` + `切到会话 0`）；
- 再开一次，Esc ⇒ `菜单: Esc ⇒ 关`，且面板色残留 < 1000 px。

负样本（变异证红，**已实测 N-k1**）：把 `tick` 里 `self.menu_keys()` 那一行注释掉
⇒ 五格红：`行=1` 不出现、`Enter 行=1` 不出现、`切到会话 1` 不出现、第二次开不出来、
`Esc 关=False`（面板残留 0 只是因为它本来就没开）；还原 ⇒ 八格全绿。

## 本片不做

· Ctrl+Shift+1/2 快捷键（面板提示里写着，但今天没有组合键通道）；
· Home/End/PageUp 与输入过滤（打字定位）；
· 未读圆点仍无生产者（ADR-100 的缺口不变）；
· 方向键从此**不再可能**进 shell —— shell 今天也没有行编辑，等它要有的时候
  再按"面板没开才放行"分流，而不是改这里。
