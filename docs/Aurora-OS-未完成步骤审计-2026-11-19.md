## 二、按总设计 §10「第一版产品命令范围」逐条核对

实测口径：`user/shell/src/registry.rs` 的 `CMD_*` 常量（25 条已实现：
`abi cat cd clear devctl dmesg echo exit free help id ip kill ls lsdev lspci part ping ps pwd run sleep top uptime whoami`）。

### §10.1 Shell 内置（9 条）：**7/9**

| 缺 | 说明 |
|---|---|
| `history` | 无命令历史缓冲，也没有上下键回溯 |
| `version` | 无版本号来源（`abi` 打的是 ABI 主次版本，不是产品版本） |

### §10.2 第一版文件命令（17 条）：**2/17** ← **最大缺口**

已有：`ls`、`cat`

| 缺 | 前置条件 |
|---|---|
| `touch` `mkdir` `rmdir` `rm` | **FAT32 写路径**（`fs-rw`，qoder 推进中） |
| `cp` `mv` | 同上（跨簇复制） |
| `stat` | 22 号有 `file_stat`，但 shell 没有命令包它 |
| `file` | 需要魔数识别表 |
| `find` | 需要递归目录遍历 API（现在只有单层 `dir_read`） |
| `grep` | 需要读 API + 模式匹配（纯用户态可做） |
| `head` `tail` `wc` | 纯用户态可做（22/24 号已够） |
| `df` `du` | 需要 `statfs`（卷几何/剩余空间），**内核侧没有这个号** |

### §10.3 第一版系统命令（12 条）：**6/12**

已有：`ps` `free` `lspci` `lsdev` `dmesg` `uptime`

| 缺 | 前置条件 |
|---|---|
| `uname` | 需要内核版本/构建信息出口 |
| `arch` | 同 `uname` |
| `meminfo` | `free` 已覆盖大部分；需决定是否另立 |
| `date` | **需要真机 RTC**（BACKLOG 76d：本 OVMF/QEMU 无可用 RTC，`apic.rs:46`） |
| `reboot` `poweroff` | **需要 ACPI 电源状态机 + 独立 ADR**（今天只有 QEMU 的 `isa-debug-exit`） |

### §10.4 第一版网络命令（5 条）：**2/5**

已有：`ip`（四个子命令全）、`ping`

| 缺 | 前置条件 |
|---|---|
| `ss` | 需要 socket 表（**Socket API 未做**） |
| `hostname` | 需要主机名存储（无 `/etc/hostname` 写路径） |
| `nslookup` | 需要 **DNS 解析器**（今天只有 `NET_DNS_IP` 常量与一次失败的 UDP 探测，ADR-141） |

## 三、按阶段列出未完成项（可直接当任务清单）

### A1 VFS/文件系统（写方向）
1. FAT32 写：`touch`/`mkdir`/`rm`/`cp`/`mv` 的内核支撑。
2. `mount`/`umount` 与 `statfs`。
3. **验收句未达成**：创建→写入→复制→重命名→删除→重启后读回的持久化闭环。

### A3 Shell 解析器（最大的一块）
1. **管道 `|`** —— 解析器零支持（`parser.rs` 只有空格分隔 argv）。
2. **重定向 `>` `>>` `<`** —— 零支持。
3. **参数/选项解析**（`ls -lah` 形状）。
4. `grep`（配合管道才有意义）。
5. `history` + 补全。
6. **验收句未达成**：`ls -lah /`、`cat file`、`echo hi > file`、`cat file | grep hi`。

### B1 设备模型
1. **统一 Device/Driver trait**（今天只有 `DriverCtx`，没有设备对象）。
2. **PCI 设备树与能力句柄**（`lspci` 是扁平枚举）。
3. 驱动匹配与生命周期、设备状态与错误恢复。
4. **`devctl` 的写操作**（bind/unbind/reset）——需要 1–3。

### B2 网络
1. **TCP**：三次握手、序号/窗口、重传、状态机。
2. **Socket API**：`socket`/`bind`/`connect`/`send`/`recv`/`close` 一族。
3. **DNS 解析器**（构造查询 + 解析应答；slirp 的 DNS 在本机离线，见 ADR-141）。
4. **DHCP 掩码/网关的动态覆盖**（今天解析了但没进全局配置槽，ADR-147 未决 1）。

### B3 时间与电源
1. **`date`**：需真机 RTC（QEMU/OVMF 上无可用 RTC）。
2. **`reboot`/`poweroff`**：需 ACPI 电源状态机 + ADR。
3. **`service status`**：需进程名（ADR-132 §未做 3）。

### B4 日志
1. **`journalctl`**：需要日志落盘（今天只有 4096B 内存环 + 持久日志尾）。

### C1 身份与权限
1. **`passwd`**：改凭据需要写权限 + 审计 + 持久化。
2. **登录会话与 `su`**：换凭据的合法路径（今天凭据是编译期档位定的）。
3. **审计日志**：`denied` 只打一行，没进持久日志环，也没有"谁/什么/何时"。
4. **凭据引用计数与销毁**：今天只增不删，表满 16 项后新建失败。
5. **更多授权闸门**：`run`（执行）应要 `CAP_EXEC`，写命令应要 `CAP_WRITE`。

### C2 软件包
1. **包版本字段**（头部改 ⇒ `PKG_VERSION` 3）。
2. **真实依赖边**（`depends: []` 恒空，需第二个包）。
3. **安装事务与回滚**、A/B 更新状态。

### C3 磁盘
1. **分区写**（创建/删除）——按裁决 ③A **不做**。
2. **`fsck`**：需 FAT32 写路径。
3. **离线恢复环境、镜像备份与恢复**。
4. **`part` 的端到端**：根卷是 FAT32 无 GPT，用户态真实 GPT 读取**未被端到端证明**（ADR-152 未决 1）。

### D3 显示
1. **合成器与窗口树**。
2. **桌面会话**（今天的 `fbcon` 有窗口/菜单/设置面板的绘制代码，但没有用户态入口）。
3. **`echo` 上屏**：44 号目前**零产品调用者**（只有 `clear` 用 45 号）。
4. **滚屏、光标、颜色**：`Term::puts` 到 `rows` 就停。

### D4 SDK
1. **`t_sdkdemo` 判据打通**：`consistent` 槽读到 0 而用户态应写 1（ADR-154 未决 1）。
2. **SDK 的 ABI 文档**：把 1–45 号的形状整理成 `docs/sdk/abi.md`。
3. **开发工具**：符号化、调试器接口、ELF 检查工具。
4. **包生态**（D5 已按裁决跳过）。

### D1 / D2 / D5
按使用者裁决 **④A / ⑤A / ⑥A 跳过**（无 xHCI、无 HDA、无安装器）。
这三项**不是遗漏，是显式决定**。

## 四、横切欠账（不属于任何单一阶段）

1. **`t_fat32` 长链抖动**：整链里偶发卷抖动，单跑必绿。已记录多次，**未归因**。
2. **`.text` 窗口反复溢出**：已第六次扩容（20→24→32→40→48 KiB）。
   根因是 shell 单二进制承载全部命令，**命令数继续增长会再次撞墙**。
   结构性解法是"外部命令化"（把 coreutils 拆成独立 ELF），但那需要 A3 的 PATH 搜索。
3. **`AGENTS.md` 与 `COORD.md` 未入库**：使用者决定，非欠账。
4. **总设计 §11.1 要求每个系统域四类测试**（单元/内核集成/用户态端到端/负样本），
   实际做到"内核 ktest + 用户态判定行 + 变异证红"三类的域占多数，
   **单元测试**（纯函数级）与**故障注入**覆盖不均。
